The storefront and checkout for Acme. Carts, discounts and tax live in src/lib; the UI is in src/components. See CONTRIBUTING.md before opening a pull request.

Getting started

npm install
npm run dev        # http://localhost:5173

RuleApplies toStacks
percentcart subtotalno
lineone line itemyes
